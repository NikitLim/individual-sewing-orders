# КТ3 — оформление индивидуального заказа на пошив

Консольная ООП-версия программы КТ2. Требуется JDK 21 или новее с поддержкой
`--release 21`. Сборка выполняется `javac`, внешних библиотек нет.

## Сборка и запуск

Из папки `src/java`:

```text
javac --release 21 -encoding UTF-8 -d out Main.java Domain.java OrderData.java OrderCheck.java OrderService.java
java -cp out Main
java -cp out Main demo 1001
```

Первый аргумент — папка с данными, второй — номер заказа. По умолчанию
используются папка `demo` и заказ 1001. В `demo` девять таблиц UTF-8 TSV
с теми же значениями, что в JSON КТ2. Первая строка каждой таблицы —
заголовок. Сохраняйте порядок столбцов из образца. Табуляция разделяет
столбцы, переводы строк разделяют записи. Даты задаются в ISO-формате
`YYYY-MM-DD`. Программа не записывает данные обратно.

## Контрольный пример

Вход — папка `demo`, заказ 1001. Комплектность и наличие материалов
подтверждены. Стоимость материалов — 8 850,00 руб., работ — 7 900,00 руб.,
итого — 16 750,00 руб. Формируется производственное задание № 1.
Дата выдачи определяется по локальному календарю, срок готовности — 2026-11-30.
Для номера `-1` программа сообщает «Заказ не найден».

Код выхода: `0` — задание выдано, `1` — в выдаче отказано, `2` — ошибка ввода.
