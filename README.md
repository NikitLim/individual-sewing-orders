# Производство швейных изделий по индивидуальным заказам

Учебная практика.

Тема: Производство швейных изделий по индивидуальным заказам.

Группа: ИКБО-10-24

Студент: Лимонов Никита

## Основной бизнес-процесс

Оформление и подготовка индивидуального заказа на пошив
швейного изделия к передаче в производство.

Основные этапы:

1. Получение заявки клиента.
2. Сбор параметров изделия.
3. Формирование заказа.
4. Согласование заказа с клиентом.
5. Передача заказа в производство.

# Предметная область

Предметной областью является производство швейных изделий
по индивидуальным заказам.

Информационная система должна обеспечивать работу с
индивидуальными заказами клиентов, их параметрами,
согласованием заказа и передачей информации в производство.
