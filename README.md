# Производство швейных изделий по индивидуальным заказам

Учебная практика РТУ МИРЭА. Студент: Лимонов Никита Алексеевич,
группа ИКБО-10-24.

## Предметная область

Оформление и подготовка индивидуального заказа на пошив швейного
изделия к передаче в производство. Система хранит данные о клиентах,
мерках, материалах и операциях, проверяет комплектность и формирует
производственное задание.

## КТ2 — аналитический этап

- `models/bpmn.bpmn` и `models/bpmn.png` — BPMN-модель процесса.
- `models/er_logical.drawio` и `models/er_logical.png` — логическая модель данных.
- `models/algo_1.drawio`, `models/algo_2.drawio` и PNG — алгоритмы.
- `src/main.py` — процедурная реализация на Python 3.12.
- `src/demo_data.json` — демонстрационные данные.
- `src/test_main.py` — автоматические тесты алгоритмов и консольного запуска.
- `src/README.md` — команды запуска и ожидаемый вывод.

Запуск из корня репозитория:

```bash
cd src
python main.py
python -m unittest -v test_main.py
```

Текущая версия использует локальный JSON и не требует базы данных.
КТ3 предполагает ООП-реализацию на Java 21 (JDK 21).

История изменений ведётся в Git; даты коммитов сохраняются без изменений.
